==============================================================
 Web-Based Hospital Management System — Local Setup Guide
==============================================================

Stack: Django 4.2 + SQLite (no external database server needed).
Works on Windows, macOS, and Linux.

--------------------------------------------------------------
 PREREQUISITES
--------------------------------------------------------------
1. Python 3.10, 3.11, or 3.12 installed and on PATH.
   Verify:
       python --version
   If `python` is not recognized on Windows, try:
       py --version
   Use `py` in place of `python` for Step 2 below if needed.

2. pip (bundled with Python). Verify:
       pip --version

3. Git. Verify:
       git --version

--------------------------------------------------------------
 STEP 1 — Get the project
--------------------------------------------------------------
    git clone <repository-url> web-based-hospital-management-system
    cd web-based-hospital-management-system

(If you already have the folder, just `cd` into it.)

--------------------------------------------------------------
 STEP 2 — Create a virtual environment
--------------------------------------------------------------
    python -m venv env

(On Windows, if `python` isn't on PATH, use:  py -m venv env)

--------------------------------------------------------------
 STEP 3 — Activate the virtual environment
--------------------------------------------------------------
Windows (PowerShell):
    env\Scripts\Activate.ps1

    If PowerShell blocks the script, run ONCE then retry:
        Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

Windows (cmd):
    env\Scripts\activate

macOS / Linux:
    source env/bin/activate

You should now see "(env)" at the start of your prompt. From
this point on, plain `python` and `pip` will use the venv.

--------------------------------------------------------------
 STEP 4 — Upgrade pip and install dependencies
--------------------------------------------------------------
    python -m pip install --upgrade pip setuptools wheel
    pip install -r requirements.txt

--------------------------------------------------------------
 STEP 5 — Apply database migrations
--------------------------------------------------------------
    python manage.py makemigrations Admin Doctor Patient
    python manage.py migrate

This creates `db.sqlite3` in the project root.

--------------------------------------------------------------
 STEP 6 — Create an admin (superuser) account
--------------------------------------------------------------
    python manage.py createsuperuser

Enter a username, email, and password when prompted.

--------------------------------------------------------------
 STEP 7 — (Optional) Collect static files
--------------------------------------------------------------
Only needed if static files don't load. For development with
DEBUG=True this is usually optional.

    python manage.py collectstatic --noinput

--------------------------------------------------------------
 STEP 8 — Run the development server
--------------------------------------------------------------
    python manage.py runserver

Open in a browser:
    Application:  http://127.0.0.1:8000/
    Django admin: http://127.0.0.1:8000/admin/

Stop the server with Ctrl+C.

--------------------------------------------------------------
 RUNNING THE PROJECT AGAIN LATER
--------------------------------------------------------------
From the project folder:
    1. Activate the venv (Step 3).
    2. python manage.py runserver

--------------------------------------------------------------
 TROUBLESHOOTING
--------------------------------------------------------------
* A package fails to build during `pip install`:
  Update pip's build tools first, then retry:
      python -m pip install --upgrade pip setuptools wheel
      pip install -r requirements.txt

* Port 8000 already in use:
      python manage.py runserver 8001

* "ModuleNotFoundError: No module named 'django'":
  The virtual environment is not activated. Repeat Step 3.

* Database looks broken / want a fresh start:
  Delete `db.sqlite3` and re-run Step 5 and Step 6.

* PowerShell error: "running scripts is disabled on this system"
  when activating the venv:
      Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

--------------------------------------------------------------
 SECURITY NOTES (before deploying anywhere public)
--------------------------------------------------------------
* SECRET_KEY, EMAIL_HOST_USER, and EMAIL_HOST_PASSWORD are
  hard-coded in Hospital_Management_System/settings.py.
  Move them to environment variables before deploying, and
  rotate the email app password.
* Set DEBUG = False and configure ALLOWED_HOSTS for production.
